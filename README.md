# 🎯Goal Reminder Bot

This is a simple Telegram bot that I created to send goal reminders every hour, cause you know I just forget to do the right things and waste my time on mobile.

## Features

- Send you goal reminders every hour. that's it!
- It requires your Telegram ID because it will only work for you.

## Commands
- You can add goals in the `config.py` file.
- `/setgoals` - If the bot is already running you can also use the `/setgoals` command to add the goals directly in Telegram.

## Variables
- `owner_id` Your Telegram ID.
- `bot_token` Your Telegram bot token from @BotFather.
- `goals_list` Your goals list.

## Setup

- Add the bot token in `config.py` file.
- Add your telegram ID that looks something like this `1234567890` in `config.py` file.
- You can find your Telegram ID using this bot - [IDBot](https://t.me/username_to_id_bot)
